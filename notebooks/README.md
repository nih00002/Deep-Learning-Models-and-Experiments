# Deep Learning Notebooks

This directory contains a curated progression of deep learning experiments, from foundational NumPy and PyTorch implementations to convolutional, recurrent, autoencoder, and transformer architectures.

## Notebooks

1. `01_NumPy_ML_Foundations.ipynb` — NumPy-based machine learning foundations
2. `02_PyTorch_ML_Foundations.ipynb` — PyTorch and autograd foundations
3. `03_CNN_CIFAR10.ipynb` — CNN image classification on CIFAR-10
4. `04_RNN_GRU_Language_Modeling.ipynb` — RNN and GRU language modeling
5. `05_LSTM_Sentiment_Analysis.ipynb` — LSTM-based sentiment classification
6. `06_Autoencoder_Representation_Learning.ipynb` — Autoencoder representation learning
7. `07_Transformers_NLP.ipynb` — Transformer-based NLP experiments
